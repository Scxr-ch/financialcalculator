# Financial Calculator


#### Description: financial calculator website where users can access multiple features such as track stocks they bought and sell, as well as check the pricing. It also has a history to view past purchases or sold stocks and a budget tracker and a savings goal to help users in their financial journey.It calls the API for the list of stocks and prices and which would update the quote page based off the value of the stock. The home page allows for users to view all their recent transactions and their current balance amount, which makes it convenient for them to view. The sell page shows a table of all the stocks the user current has, and allows for the user to choose the amount they want to sell. The history gives the user a overview on what the user has bought and sold, and the timing where the user place the order or sold the stock. The savings goal allows for the user to plan out his savings goal, by displaying how much the user needs to reach the target amount the user wants in the number of years he can set, which will aid the user in achieving the goal and planning out the users financial desicisions on how to achieve that goal 
To start run the website on local host.

to run the local host server, cd the project folder by typing : cd project
afterwards, execute the command flask run
